# Icons

Place the extension icons here (referenced by `manifest.json`):

- `icon16.png` — 16×16 (toolbar)
- `icon48.png` — 48×48 (extensions page)
- `icon128.png` — 128×128 (Chrome Web Store / install)

Until real icons are added, either drop placeholder PNGs here or remove the
`"icons"` block from `manifest.json` to load the extension without them.
